One sentence, 266 characters, that brings back a childhood memory: "My grandmother always saved me the burnt crust from the bottom of the rice pot, scraping it into my bowl with her wooden spoon on summer evenings while cicadas sang outside the kitchen window, and I have spent my whole grown-up life trying to taste that crust again." The program in `main.ts` writes that single line to `entry.txt` in the output directory, after checking it fits the 1–280 character gate.

## Run it

```sh
node main.ts
```

This writes `/output/entry.txt`. Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose the output directory.
